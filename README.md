# Palmira Lab

Студия автоматизации и ИИ-решений: сайты и лендинги, автоматизация
рутины (Telegram-боты, публикация контента, отчёты), ИИ-консультации.

## Статус

Ранняя стадия — черновой лендинг (`index.html`), рабочий чат-ассистент
на главной странице ещё не построен.

## Структура

- `index.html` — лендинг: hero, услуги, кейсы, контакт.

## Планы

Чат-ассистент на главной странице: посетитель описывает задачу,
получает уточняющие вопросы и предварительное предложение. Технически
— Next.js + NestJS + PostgreSQL, разворачивается на VPS через Docker.
